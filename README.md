# 任禹桐 · 个人名片网站

一个为开学自我介绍准备的**极简高级宇宙星系质感**个人名片网站。深邃写实的星空背景、舒缓流动的星云粒子、径向圈层的阅读星图，配合 Node.js + Express 后端，实现「内容后台可管理、前台自动刷新」，全程**不引入任何第三方图表库、外部图片与重型前端框架**。

---

## 一、功能总览

| 板块 | 路由 | 说明 |
|------|------|------|
| 主页 | `/` | 姓名 + 一句话介绍，全屏舒缓星云粒子背景 |
| 项目 | `/projects` | 项目卡片网格，内容由后台管理 |
| 关于我 | `/about` | 个人介绍 + 技能 + 联系方式 |
| 阅读 | `/reads` | **径向圈层星图**：中心 ME、多层轨道、书单/笔记按知识象限分区 |
| 后台管理 | `/admin` | 可视化新增 / 编辑 / 删除项目与阅读，保存即生效 |

### 视觉设计要点

- **配色**：深空黑、暗靛蓝、星云紫、星尘青、淡胭脂红，低饱和、弱高光，拒绝艳丽刺眼。
- **星云背景**：原生 Canvas 手写粒子，粒子有远近大小 / 明暗视差，缓慢漂移旋转，不抢文字阅读优先级。
- **阅读星图**：中心原点 `ME`，向外多层同心环形轨道，星体节点自带微弱星芒光晕，轨道极细半透深空灰，整套星图缓慢自转，鼠标悬浮星体平滑弹出书名与简介。

## 三、本地运行教程（一步一步）

### 第 1 步：安装 Node.js

本网站需要一个叫 **Node.js** 的运行环境。如果你还没有安装：

1. 打开官网 <https://nodejs.org/>
2. 下载 **LTS（长期支持版）** 安装包（Windows 推荐 `.msi`）
3. 双击安装，一路「下一步」即可（默认会自带 `npm`）

安装完成后，验证是否成功：按 `Win + R`，输入 `cmd` 回车，在命令行里执行：

```bash
node -v
```

如果显示类似 `v18.x.x` 的版本号，说明安装成功。

### 第 2 步：进入项目目录

把 `renyutong-card` 整个文件夹放到你喜欢的位置。然后在命令行（cmd 或 PowerShell）里 `cd` 进去：

```bash
cd C:\Users\你的用户名\renyutong-card
```

> 提示：在资源管理器地址栏输入 `cmd` 回车，可直接在当前目录打开命令行。

### 第 3 步：安装依赖

在项目目录下执行（只需要执行一次）：

```bash
npm install
```

它会根据 `package.json` 自动安装 `express` 到 `node_modules` 目录。

### 第 4 步：启动服务

任选一种方式：

**方式 A（推荐，一键启动）**：双击 `start.bat`（会自动打开浏览器）

**方式 B（命令行）**：

```bash
npm start
```

看到如下提示就说明启动成功：

```
任禹桐 · 个人名片网站 已启动
主页：  http://localhost:3000/
阅读：  http://localhost:3000/reads
后台：  http://localhost:3000/admin
```

### 第 5 步：打开浏览器访问

在浏览器地址栏输入：

- 主页：<http://localhost:3000/>
- 阅读星图：<http://localhost:3000/reads>
- 后台管理：<http://localhost:3000/admin>

停止服务：回到命令行窗口按 `Ctrl + C`（或直接关闭 `start.bat` 窗口）。

## 四、如何管理内容

### 方式 A：后台可视化管理（推荐）

访问 <http://localhost:3000/admin>：

> 后台有口令保护，默认口令为 `admin123`，登录后才能增删改（修改方法见文末「常见问题」）。

1. **新增项目**：填写「项目名称 / 描述 / 标签 / 链接」，点「新增项目」。
2. **编辑 / 删除**：每条记录右侧有「编辑」「删除」按钮。
3. **阅读管理**：同理，可新增书 / 笔记，填写「知识象限（分类）」，星体会按分类归入对应扇形区域。
4. 保存后**无需修改任何前端代码**：
   - `/projects` 刷新即更新；
   - `/reads` 星图会在 30 秒内自动刷新（或切回该页面时立即刷新）。

### 方式 B：直接编辑 JSON 文件

用记事本打开 `data/` 目录下的文件，按同样格式增删即可（保存后同样生效）：

- `data/profile.json` —— 改姓名、简介、技能、联系方式
- `data/projects.json` —— 改项目
- `data/reads.json` —— 改书单 / 笔记

## 五、数据字段说明

**项目 `projects.json` 中的一条：**

```json
{
  "id": "p-1",
  "title": "个人名片网站",
  "description": "一句话描述……",
  "tags": ["Node.js", "Canvas"],
  "link": "https://github.com/asl-op",
  "createdAt": "2026-08-13"
}
```

**阅读 `reads.json` 中的一条：**

```json
{
  "id": "r-1",
  "type": "book",        // book = 书（实心圆点），note = 笔记（空心圆环）
  "title": "三体",
  "category": "科幻",     // 知识象限：相同分类会归入同一扇形区域
  "status": "已读完",
  "note": "一句话简介或笔记要点"
}
```

> 小技巧：`category` 写什么都会自动成为一个新的「知识象限」，并分配对应颜色与图例。

## 六、常见问题

**Q：双击 start.bat 一闪而过？**
多半是未安装 Node.js。先完成「第 1 步」。

**Q：浏览器打不开 / 显示「无法访问」？**
确认命令行窗口没有报错、服务仍在运行；确认地址是 `http://localhost:3000/`。

**Q：端口 3000 被占用了？**
可在启动前设置环境变量换端口，例如命令行执行 `set PORT=4000` 后再 `npm start`，然后访问 `http://localhost:4000/`。

**Q：改完 JSON 星图没变？**
`/reads` 每 30 秒自动刷新，或切换到该页面（聚焦）时立即刷新；也可以直接手动刷新浏览器。

**Q：后台登录的口令是什么？怎么改？**
默认口令是 `admin123`。修改方法（二选一）：
- 本地：编辑 `server.js`，把 `const ADMIN_PASSWORD = process.env.ADMIN_PASSWORD || 'admin123';` 里的 `admin123` 改成你自己的口令；
- 更安全：设置环境变量 `ADMIN_PASSWORD`（部署到 Glitch/Render 时在平台的环境变量里设置），这样口令不会出现在代码里。

## 七、技术栈说明

- **后端**：Node.js + Express，轻量 JSON 文件存储（`data/`），无需数据库，新手友好。
- **前端**：原生 HTML / CSS / JavaScript，星云粒子与径向星图全部手写 Canvas，无第三方图表库、无外部图片、无重型框架。
- **动画性能**：`requestAnimationFrame` 驱动，粒子数量随屏幕面积自适应，限制 `devicePixelRatio` 最高 2 倍，帧率稳定、低消耗。
