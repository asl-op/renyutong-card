# 任禹桐 · 动态个人名片网站

一个**高级极简宇宙星系质感**的个人名片网站，前端为太阳系同心环形星轨布局，后端用 Node.js + Express + 轻量 JSON 文件存储，无需数据库，新手友好。

> 主题：深空黑 / 暗靛蓝 / 星云紫 / 星尘青，光影柔和内敛，动画缓慢顺滑，不抢阅读焦点。

---

## 二、本地运行教程（逐行）

### 第 1 步：安装 Node.js（已装可跳过）

1. 打开浏览器访问 <https://nodejs.org>
2. 下载 **LTS 版本**并安装（一路默认即可）
3. 打开命令行（Win + R 输入 `cmd` 回车），输入下面命令验证：

```bash
node -v   # 应显示版本号，如 v20.x 或更高
npm -v    # 应显示版本号
```

### 第 2 步：下载 / 解压本项目

把整个 `renyutong-card` 文件夹放到任意位置（例如桌面），记住路径。

### 第 3 步：安装依赖（只需第一次）

进入项目文件夹，打开命令行（在文件夹地址栏输入 `cmd` 回车即可），执行：

```bash
npm install
```

> 看到 `node_modules` 文件夹出现即安装成功。本项目只依赖 `express` 一个包。

### 第 4 步：启动服务

两种方式任选其一：

**方式 A —— 双击启动（推荐，最省事）**

双击 `start.bat`，脚本会自动：
1. 检查 Node.js 是否安装
2. 首次自动执行 `npm install`
3. 启动服务器
4. 自动打开浏览器到 `http://localhost:3000`

**方式 B —— 命令行启动**

在项目文件夹内执行：

```bash
node server.js
```

看到如下提示即启动成功：

```
==============================================
  任禹桐 · 个人名片网站 已启动
  请打开浏览器访问：http://localhost:3000
  后台管理地址：    http://localhost:3000/admin
==============================================
```

### 第 5 步：打开网站

浏览器访问：

| 页面 | 地址 |
|------|------|
| 主页 | http://localhost:3000 |
| 项目 | http://localhost:3000/projects |
| 关于我 | http://localhost:3000/about |
| 阅读 | http://localhost:3000/reads |
| 后台管理 | http://localhost:3000/admin |

## 三、如何修改内容（后台可视化管理）

1. 打开 **http://localhost:3000/admin**
2. 顶部可切换「项目 / 阅读」
3. 右侧表单填写 → 点「新增并保存」
4. 列表中可「编辑」「删除」任意一条
5. 保存后，回到「项目」或「阅读」页面，星轨上的星体会**自动刷新渲染**，无需改动任何前端代码

> 也可以直接编辑 `data/projects.json`、`data/reads.json`、`data/site.json`，改完刷新页面即可（推荐用后台界面，更直观）。

### 字段说明

| 字段 | 说明 |
|------|------|
| 标题 | 星体节点下方显示的文字 |
| 简介 | 悬浮卡片里的说明 |
| 分类 | 相同分类会分布到**同一条星轨**上 |
| 链接 | 可选，有则卡片显示「查看详情」 |
| 日期 | 卡片里的时间信息 |
| 标签 | 用逗号分隔，卡片里以斜杠连接显示 |

### 修改个人信息

编辑 `data/site.json`，可更新姓名、简介、邮箱、GitHub、微信、QQ 等，主页与「关于我」页面会自动更新。

## 四、常见问题

- **双击 start.bat 闪退？** 说明没装 Node.js，先完成「第 1 步」。
- **端口被占用？** 用 `PORT=4000 node server.js` 换端口启动（浏览器访问 `http://localhost:4000`）。
- **改了 JSON 没反应？** 刷新页面即可；若在后台界面保存失败，请确认服务还在运行。
- **想换成 HTTPS 或部署到公网？** 本项目为本地个人展示用途，数据无鉴权，请勿直接暴露到公网。

## 五、技术说明

- 后端：Node.js + Express，数据读写本地 JSON 文件
- 前端：纯原生 HTML/CSS/JS，**无前端框架、无图表库、无外部图片**
- 动画：`requestAnimationFrame` 驱动星云粒子与星轨自转，低性能消耗、帧率稳定
- 路由：`/`、`/projects`、`/about`、`/reads`、`/admin` 严格规范

## 六、分享到公网（让任何人都能打开）

本地 `localhost` 只能自己访问，想让同学 / 老师直接打开，可用系统自带的 SSH 建立免费公网隧道（无需注册、无需下载任何工具）：

1. 先确保网站已启动（双击 `start.bat`，或运行 `node server.js`）
2. 双击 **`share.bat`**，脚本会自动建立隧道
3. 控制台出现类似 `https://xxxx.serveousercontent.com` 的地址，复制发给任何人即可访问

**后台管理密码**：本地首次启动时自动生成随机密码，并在控制台打印（同时保存在 `data/.admin-password`，该文件已加入 `.gitignore`，不会提交）。部署到 Render 时，请在 Render 控制台的 Environment 里设置 `ADMIN_PASSWORD` 环境变量。

**注意事项（重要）**：

- 公网地址是**临时随机**的，每次重启隧道都会变化
- 隧道只在「你的电脑开机 + 脚本窗口未关闭」时有效，关机或关闭窗口即失效
- 隧道服务在境外，国内访问速度可能较慢
- 如需**永久固定网址**，建议把项目部署到 Render / Railway 等免费平台（需 GitHub 账号），需要的话可以让 Claude 帮你完成
